# Personal GitHub Pages Blog

这是一个纯静态个人博客模板，可直接部署到 GitHub Pages。

## 文件结构

```text
index.html
assets/styles.css
assets/site.js
.nojekyll
```

## 修改内容

打开 `assets/site.js`，修改：

- `githubUser`
- `repositories`
- `courses`
- `journal`

## 发布到 GitHub Pages

1. 在 GitHub 创建仓库：`你的用户名.github.io`
2. 把本目录所有文件上传到该仓库
3. 进入仓库 `Settings` -> `Pages`
4. Source 选择 `Deploy from a branch`
5. Branch 选择 `main` 和 `/root`
6. 访问 `https://你的用户名.github.io`
